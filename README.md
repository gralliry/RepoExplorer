# RepoExplorer

RepoExplorer 是一个桌面端 Git 仓库文件浏览与管理工具。它把远端仓库呈现成类似 Windows 资源管理器的界面，让你可以像操作文件夹一样浏览、下载、上传和整理仓库文件。

## 功能特点

- 浏览仓库目录和文件
- 搜索仓库内文件
- 下载文件或文件夹到本地
- 上传文件或文件夹
- 新建文件和文件夹
- 复制、剪切、粘贴、移动、重命名、删除
- 支持选择模式：点击“选择”后勾选多个项目再批量操作
- 操作过程显示任务进度
- 错误信息不会自动消失，可复制，点击关闭才关闭
- 写操作会直接提交到远端仓库

## 当前支持

| 类型 | 状态 |
|---|---|
| GitHub 公开仓库 | 支持浏览和下载 |
| GitHub 私有仓库 | 登录后支持 |
| GitHub 写操作 | 需要登录且拥有写权限 |
| GitLab / Gitee / 其它 Git 服务 | 暂未支持 |
| 本地 Git 仓库 | 暂未支持 |

> 输入 `owner/repo` 时默认按 GitHub 仓库处理。

## 使用方法

### 打开仓库

点击 **打开仓库**，可以选择：

- 从“我的仓库”列表里打开
- 手动输入公开仓库地址

支持的 GitHub 地址格式：

```text
owner/repo
https://github.com/owner/repo
git@github.com:owner/repo.git
```

### 登录

点击右上角设置按钮进入账号设置。

登录方式二选一：

- **GitHub 登录**：推荐方式
- **Token 登录**：手动填写 Personal Access Token

两种方式任选一种即可，不需要同时填写。

### 选择文件

- 默认单击项目会选中
- 点击顶栏 **选择** 后进入选择模式，项目前会出现复选框
- 再次点击 **取消** 会退出选择模式并清空选择
- 顶栏和右键菜单里的操作都会基于当前选中的项目执行

### 常用操作

顶栏和右键菜单都提供：

- 复制
- 剪切
- 粘贴
- 重命名
- 删除
- 下载

新建和上传在顶栏菜单中：

- **新建 ▾**
- **上传 ▾**

上传文件夹时会保留最外层文件夹名。

## 权限说明

未登录时只能打开公开仓库，通常只能浏览和下载。

需要登录的操作：

- 打开私有仓库
- 上传
- 新建
- 重命名
- 移动
- 复制/剪切/粘贴
- 删除

如果仓库没有写权限，相关按钮会被禁用。

## 写操作说明

所有写操作都会直接提交到当前分支。

包括：

- 上传文件或文件夹
- 新建文件或文件夹
- 重命名
- 移动
- 复制
- 剪切/粘贴
- 删除

请注意：

- Git 不支持真正的空文件夹，所以新建文件夹时需要同时创建里面的第一个文件
- 删除是真实删除，但可以从 Git 历史中找回
- 如果操作时分支被别人更新，可能会提示冲突；刷新仓库后重试即可

## 打开文件

双击文件会先下载到本地临时目录，然后用系统默认程序打开。

本地临时文件的修改不会自动写回仓库。如果需要更新仓库内容，请使用上传功能覆盖原文件。

## 常见错误

| 错误 | 说明 |
|---|---|
| 401 | 登录失效或 Token 不正确，请重新登录 |
| 403 | 权限不足或请求过于频繁 |
| 404 | 仓库、分支或文件不存在；私有仓库可能未授权 |
| 409 | 分支内容已变化，刷新仓库后重试 |
| 502 / 503 / 504 | 远端服务临时异常，稍后重试 |

## 构建产物

应用构建后生成：

```text
build/bin/RepoExplorer.exe
```
